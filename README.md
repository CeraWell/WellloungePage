# 웰라운지 운영 상황판

- **매장별 실적 리포트** — `index.html` → https://cerawell.github.io/WellloungePage/
- **운영 상황판** — `ops/index.html` → https://cerawell.github.io/WellloungePage/ops/

## 상황판 구성

종합 · 계약수량 · 코치 · 모객 · 데일리 5개 탭. 팀 / 지역장 / 등급 필터와 기간 선택이
모든 탭에 함께 적용되며, 지표는 선택한 기간으로 다시 계산됩니다.

판매 실적은 **금액이 아니라 계약수량(대)** 기준입니다 — 일별매출 탭의 1행 = 1계약 = 1대.

## 데이터 출처

구글시트 `세라젬_매장운영_취합양식`
(`1D8u0-YTbuVQ6ZY31y7WH_GfNXtR9j-CNGq9ZDqjkS-0`) 의 5개 탭을 **매장코드**로 조인합니다.
매장명은 탭마다 표기가 달라 키로 쓰지 않습니다.

## 갱신 방법

```bash
# 1) 구글시트를 xlsx 로 내려받아 live.xlsx 로 둔다
# 2) 빌드
python3 build/build_ops.py live.xlsx .
# 3) 커밋 & 푸시 → GitHub Pages 가 자동 배포
git add ops/index.html && git commit -m "상황판 갱신" && git push
```

`build/head.html` 은 레이아웃·문구, `build/app.js` 는 지표 계산과 렌더를 담당합니다.
데이터는 두 개의 JSON 으로 페이지 안에 박혀 있어 외부 요청 없이 단독 실행됩니다.

## 지표 정의

- **충족률** = 내부코치 ÷ 적정코치수 (점장·외부코치 제외)
- **전환율** = 신규결제건수 ÷ 총방문(워크인+클래스)
- **성과지수 / 인력지수** — 소속 등급 중앙값을 100으로 놓은 상대값. 등급이 다른 매장끼리 비교 금지
- **전년비** — 선택 기간과 같은 달의 전년치. 전년 데이터가 다 있을 때만 표시

## 알려진 데이터 이슈

- 김천혁신도시점·부산연산점은 매장마스터에 없어 집계에서 빠집니다
- 거제고현점은 일별매출에 매장코드가 없어 계약수량이 0입니다
- 서울목동·파주운정·인천계양점은 유료회원이 미입력이라 유지 진단에서 제외됩니다
- 코치 데이터는 스냅샷이라 기간 선택의 영향을 받지 않습니다
